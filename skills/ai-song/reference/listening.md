# 人说一句话，先去量什么

人听歌的描述通常很准，只是只有一句。把它对到要量的东西上，先量，再决定改哪一步。

| 人说 | 先量什么 | 我们那首查出来的原因 |
|---|---|---|
| 「不连贯」「有的地方没有伴奏」 | 每小节伴奏电平（`bar_levels.py`） | 模型的伴奏提前停了，或者手工撤了层 |
| 「没接好」「后面一两小节不好」 | 拼接处的速度、和弦循环位置、每半小节电平；八分音符上的相位和每小节的重音（`beat_check.py`） | 原伴奏在句尾停了，补上的循环没有旋律 |
| 「不好听」「没有韵律感」 | 每半小节电平；主奏有没有动机（`lead_notes.py`） | 电平挖出一个 10 dB 的洞，只剩循环 |
| 「怪」「跟伴奏合得不好」 | 字落在拍子上的比例、音落在和弦里的比例（`fit_check.py`） | 见下表 |
| 「平」 | 音域、每句的音高走向 | 女声说唱只有 5.7 个半音 |
| 「像磁带坏了」 | 是不是整段混音一起变速了 | 是，人声的辅音和转音也被拉慢了 |
| 「太激昂」「不适合这首歌」 | 指标查不出 | 这是形式问题，回到「先出形式样片」 |
| 「衔接不自然」（结尾） | 频谱图上看鼓在哪儿停、人声停后有没有空一下 | 鼓在小节中间被拉掉，铺底又回来，接缝太多 |
| 「一点都没有参考歌的味道」 | 和弦走向、音阶色彩、鼓的律动，和参考歌比（`harmony_groove.py --compare`） | 一次测试里：参考歌是安达卢西亚终止、属音上方的 b2、3+3+2；样片是流行和弦、二四拍反拍 |
| 「主旋律在中间换了」 | 是不是两次生成拼起来的 | 是，主歌和副歌分开出、用了不同的风格描述 |
| 「副歌太赶」「副歌太短」 | 每段每句几小节（`take_sections.py`，再 `take_grid.py --sections`） | 一次测试里副歌跟着主歌的字速，每句约 1 小节，计划是 2 小节 |

## 贴合检查的参考数字

格子容差 ±40 毫秒。随便放的话，大约 53% 的字会落在 16 分音符上，26% 落在八分音符上，25% 的音落在和弦内。

| 段落 | 每秒几个字 | 落在 16 分音符上 | 落在八分音符上 | 在和弦内 |
|---|---|---|---|---|
| 人接受的说唱段 | 2.6 | 0.80 | 0.60 | 0.67 |
| 人说「怪」的说唱段 | 4.6 | 0.46 | 0.25 | 0.30 |
| 同一段重唱以后 | 3.8 | 0.76 | 0.38 | 0.59 |

这些数字只来自一首歌，只能作参考。和弦判断也比较粗（低音最强的音，加上更强的那个三度）。

## 从好歌学到的句子特点

我们分离过一首参考歌的人声，量了它的句子（这些规律只用来写提示和筛候选，参考歌的音频和音符不进生成）：句子短（中位数 2.7 秒），长短差得大，69% 的时间在唱，最高音在句子中间，句尾往下落的只占 30%。我们自己开头那段，每句一开口就是最高音。按这些特点筛出来的版本，数字确实更接近，人听了还是觉得原来的好。数字接近，不等于好听。
