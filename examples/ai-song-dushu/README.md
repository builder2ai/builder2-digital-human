# 试跑样歌《赌书》

这是 [AI 作曲 skill](../../skills/ai-song) 的一次完整试跑。我们新开了一个 Claude Code 会话，除了这个 skill 什么都没给它，让它照一首西班牙风格的流行歌，给一位古人写一首短歌。它写的是李清照和赵明诚「赌书泼茶」的故事。

试听：[dushu_sample.mp3](dushu_sample.mp3)（40 秒：前奏、一段主歌、一段副歌、结尾）

> 这首歌是 AI 生成的，歌声不是真人。主体用 YuE2 作曲，前奏和结尾用 ACE-Step 1.5 补写。

## 每一步做了什么

| 步骤 | 结果 |
|---|---|
| 扒参考歌：分层，量速度、调、段落、和弦、鼓的律动 | 跑通 |

| 改唱错的字 | 跑通，有一个字没改好，见下面 |

改字、念白、前奏、结尾和交付检查这几步一共用了大约 23 分钟显卡。试跑里发现的问题，我们已经改进了 skill。

## 参考歌只用来量

参考歌是别人的作品。它的音频、分出来的人声和伴奏、歌词，只在我们自己的电脑上用来量数字，没有交给任何生成模型，也不放在这个仓库里。

量出来它有三个特点：副歌的和弦走安达卢西亚终止，人声常落在属音上方的 b2，鼓是 3+3+2。前两轮风格描述没写到这几样，出来的都是普通流行歌。第三轮把它们换成 flamenco、rumba 这类模型认得的风格词，一共出了 12 版（YuE2 8 版，ACE-Step 1.5 4 版），没有一版三样都有。我们挑了三版各有一样的做成样片，人听过以后，觉得按这首词，鼓是 3+3+2 的那一版最合适。

## 这首歌是怎么做出来的

**主体**
- 模型：YuE2，ComfyUI 打包版的 `yue2_3b_int8_convrot.safetensors`，种子 701。风格描述和歌词见 [spec_yue2.json](spec_yue2.json)，配 skill 里的 `scripts/render_yue2.py` 用。
- 量出来是 D 小调，每分钟约 104 拍。风格描述里写的是 G 小调、105 拍，YuE2 不照着唱。
- 鼓：主歌和副歌都是 3+3+2。和弦是流行歌的常见走法，没有安达卢西亚终止。
- 在 NVIDIA DGX Spark 上，YuE2 出 8 版一共 368 秒。

**改字**
- 办法：同一套音符换一个渲染种子，重新出一遍声音。旋律和节奏不变，咬字会变，每次 18 秒左右。
- 第 1 句「每回吃过了饭」原来听着像「每回去」，第 7 句「翻开来」原来像「放开来」。从听得更清楚的一版里，把第 1 句、第 7 到 8 句、第 11 到 12 句贴回去，接在换气的地方。
- 用 Whisper 听写，和歌词对得上的字从约 0.90 到约 0.94。听写本身每次会差一两个字，只能看大方向。
- 没改好的：最后一句「茶泼进怀里」的「茶」，听写一直听成「擦」或「插」。换了 5 个种子，又从这个字前面重唱了 4 次，都没有明显更好。

**前奏和结尾**
- 前奏：ACE-Step 1.5 从主歌的伴奏往前补了 4 小节，同一个调、同一个速度。
- 结尾：同样往后补，最后一句唱完再走一小节多，落在 D 上。
- 接缝都在小节线上。接上的地方和原来那段是同一段声音，量出来相关度 0.999。

**念白**
- 原来打算在结尾加一句赵明诚的「这杯不算，再来。」，用 Qwen3-TTS 按文字描述设计了一个男声，不克隆任何真人。
- 做出来混进去了，人听了觉得太怪，最后没放。这一步的做法还留在 skill 里。

**成品**
- 40.4 秒，响度 -17.0 LUFS，真峰值 -1.6 dBTP（mp3 是 -17.3 LUFS、-1.9 dBTP）。
- 要到 -16 LUFS，只调音量会让峰值超过 -1.5 dBTP，所以没有硬推。skill 里现在有一个可选的限幅器，开了以后可以到 -16 LUFS。

## 歌词

[lyrics.txt](lyrics.txt) 是交给作曲模型的样子，主歌两句排一行。

```
每回吃过了饭，就坐进归来堂
炉子上茶正烫，书堆了半面墙
你伸手指着讲，哪件事，在哪本上
翻开来对一对，谁说中，谁先尝

第几页，第几行
我连想都不用想
端起杯，笑得直晃
茶泼进怀里，没喝上
```

用李清照的口吻写，「你」是赵明诚，整首押 ang。

## 出处

故事出自李清照《金石录后序》：

> 每饭罢，坐归来堂烹茶，指堆积书史，言某事在某书某卷第几叶第几行，以中否角胜负，为饮茶先后。中即举杯大笑，至茶倾覆怀中，反不得饮而起。

| 歌词 | 原文 | 说明 |
|---|---|---|
| 每回吃过了饭，就坐进归来堂 | 每饭罢，坐归来堂 | 原文 |
| 炉子上茶正烫 | 烹茶 | 「炉子」是加的画面 |
| 书堆了半面墙 | 指堆积书史 | 「半面墙」是加的 |
| 你伸手指着讲，哪件事，在哪本上 | 言某事在某书某卷 | 原文 |
| 翻开来对一对 | 以中否角胜负 | 原文只说按说中没说中定输赢，翻书核对是推出来的 |
| 谁说中，谁先尝 | 为饮茶先后 | 原文 |
| 第几页，第几行 | 第几叶第几行 | 「叶」改成「页」，一听就懂 |
| 我连想都不用想 | 余性偶强记 | 原文说她记性好 |
| 端起杯，笑得直晃 | 中即举杯大笑 | 「直晃」是加的，接下一句 |
| 茶泼进怀里，没喝上 | 至茶倾覆怀中，反不得饮而起 | 原文。笑翻了茶的是说中的那个人 |

「赌书泼茶」这四个字不在后序里，是后人的概括，常见的出处是纳兰性德《浣溪沙》里的「赌书消得泼茶香」。
